# ttsp

*this too shall pass.* Registro de humor pessoal para iPhone: dois registros por dia, uma cor por registro e uma leitura objetiva de como o bem-estar flutua.

- Especificação completa: [`docs/SPEC.md`](docs/SPEC.md)
- Sistema visual aprovado: [`docs/design-system.html`](docs/design-system.html)

Os dados ficam só no aparelho. Este repositório contém apenas código.
